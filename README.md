# Proyecto 1 - Python Fundamentals

Aplicación interactiva en Streamlit desarrollada como Proyecto 1 del Módulo 1 (Python Fundamentals) de la Especialización en Python for Analytics.

## Contenido de la app

- **Home**: presentación del proyecto y datos del estudiante.
- **Ejercicio 1**: flujo de caja con listas (ingresos y gastos).
- **Ejercicio 2**: registro de productos con arrays de NumPy y DataFrame.
- **Ejercicio 3**: uso de una función de `libreria_funciones_proyecto1.py` (cálculo de depreciación en línea recta).
- **Ejercicio 4**: uso de la clase `InventarioProducto` de `librería_clases_proyecto1.py` con operaciones CRUD.

## Cómo ejecutar la app localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Archivos del proyecto

- `app.py`: aplicación principal.
- `libreria_funciones_proyecto1.py`: librería de funciones proporcionada por el curso.
- `librería_clases_proyecto1.py`: librería de clases proporcionada por el curso.
- `requirements.txt`: dependencias del proyecto.
